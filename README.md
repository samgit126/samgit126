## Research code

- [**storypoint-calibrated**](https://github.com/samgit126/storypoint-calibrated) — story-point estimation with split-conformal prediction intervals on the 16-project Choetkiertikul corpus; baselines, a CodeBERT regressor, MAPIE intervals, figures. Work towards an EASE 2027 submission.
- [**cosmic-issue-labels**](https://github.com/samgit126/cosmic-issue-labels) — a reproducible protocol for sizing issue-tracker items in COSMIC function points (ISO/IEC 19761), with a validator and worked examples; the labelled dataset is released here as it passes adjudication.
